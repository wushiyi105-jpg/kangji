# UI 说明：康记

- **谁在什么时刻打开**：给替家人整理药盒的人。
- **首屏任务句**：家里哪些药，重复了。
- **主操作**：按「按储位录药 → 查重复成分 → 带走待问清单」推进；首屏先给输入和主按钮，结果区在下方或右侧。
- **主信息结构**：分格药柜；对比、时间线、原文与修订、队列或价签按任务选择，而不是通用卡片堆叠。
- **三种状态**：空状态指到第一步；已有内容显示结果、来源/计算依据和导出入口；失败或待确认时保留已填内容，并在原位置说明缺什么。
- **视觉原型**：分格药柜。底色、强调色、圆角、边框和数字字体都按该任务重定，遮住产品名后仍能从布局看出用途。
- **解释**：给替家人整理药盒的人：登记药名、成分、规格、有效期和存放处，重复成分与临期项目直接排在首屏。
